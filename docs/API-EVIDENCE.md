# API 및 파일 형식 참고

씬북의 공통 요청 모듈과 이미지 메타데이터 판독기는 다음 공식 자료의 API·파일 형식을 참고합니다.

- [SillyTavern 소스](https://github.com/SillyTavern/SillyTavern)
- [NovelAI 문서](https://docs.novelai.net/)
- [NovelAI 공식 이미지 메타데이터 도구](https://github.com/NovelAI/novelai-image-metadata)

PNG의 일반 텍스트 정보와 알파 채널의 압축 JSON 메타데이터를 읽습니다. 메타데이터 표시가 이미지 출처나 서명의 진위를 인증하는 것은 아닙니다.
