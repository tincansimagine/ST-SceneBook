# 씬북 기능 대조표

2026-09-21. 참고 코드를 읽었다는 사실과 해당 기능을 구현했다는 사실을 구분한다. 아래의 구현은 실제 유료 API 품질 검증을 뜻하지 않는다.

| 출처에서 확인한 장점 | 씬북 상태 | 구현 또는 남은 부분 |
|---|---|---|
| 오토픽 · ST 안에서 설정 | 구현 | 기본 inline-drawer, 테마 상속, 짧은 메뉴, /scenebook |
| CSP · 화면 위 인물 배치 | 구현 | 배치 탭, 드래그/클릭/방향키, 균등 배치/뒤집기, 기존 그림 위 편집, 모델별 좌표 |
| CSP · 당시 설정으로 리롤 | 구현 | 모델·시드·설정을 작업별 저장. 같은/새 시드, 이전 버전, 나란히 비교 |
| CSP/LB · 범위를 정한 수정 | 구현 | 전체/구도/배경/인물. 범위 밖 필드와 삽입 지점을 코드로 고정 |
| CSP · 고정 외형과 복장 분리 | 구현 | 기본 외형, 기본 복장, 장면 동작. 이름 또는 ID 매칭 |
| CSP · POV 플레이어 | 일부 | 화면 밖 인물 제외. 별도 신체 조각 프로필과 자동 가시성의 실사용 품질 검증은 남음 |
| CSP/Comfy · 채팅별 외형 프로필 | 구현 | 계정 기본값/채팅별 설정, 인물당 외형 프로필 10개 |
| Comfy · 의상 변경 타임라인 | 일부 | 정밀 모드의 인용 근거·문단 내 시점 적용. 장편 평가, 장기 증분 캐시 남음 |
| LB/Comfy · 안전한 문단 삽입 | 구현 | 코드/상태창/긴 인용 보호, 원문 근거 확인, 안전한 DOM 앵커가 없으면 말미 표시 |
| LB · 부분 실패 보존 | 구현 | 유효 장면 보존. 수정 실패 장면은 이전 초안 유지. 무한 재시도 없음 |
| LB · JSON 형식 자동 수선 | 일부 | 코드 펜스 제거와 엄격한 검증만 제공. 임의 의미 변경을 동반하는 자동 복구는 없음 |
| CSP/오토픽 · Vibe/Precise | 구현 | V4.5 등록·적용·인코딩 캐시. V5 미지원 입력은 명시적으로 차단 |
| CSP · 자연어와 태그 분리 | 일부 | 모델별 분석 지시, 인물/구도/배경 분리. 태그·caption 각각의 독립 편집과 정확한 토큰 계측은 남음 |
| CSP · 태그북 | 미구현 | 원문 사전/번역을 무단 배포하지 않으며 독립 사전 공급 방법 필요 |
| CSP · 시각 로어북 | 일부 | 명시적 세계관 입력. ST 로어북 자동 검색과 출처 표시 남음 |
| CSP · 저장 원본과 적용 참조 분리 | 구현 | 서버 참조 라이브러리와 적용 목록을 별도로 관리 |
| Comfy · 기존 에셋 재사용 | 일부 | 생성 이력 삽입 가능. 사용자 에셋 자동 선택과 외부 워크플로 연결 남음 |
| Comfy · 비전 검수 | 일부 | 단일 이미지 선택 검수와 서버 저장. 세트 연속성·한도 있는 자동 개선 남음 |
| LB/Comfy · 다중 컷/키비주얼/대사 | 미구현 | 여러 독립 삽화 생성은 가능하지만 만화 패널 구성·말풍선 레이어는 아님 |
| Comfy · 영역 마스크/영상 | 미구현 | NAI 인물 중심 좌표와 Comfy 영역 마스크는 같은 기능으로 취급하지 않음 |
| 공통 · 중복 과금/복구 | 구현 | 사용자별 잠금, 지속 작업 ID, 불확실한 결과 자동 재전송 금지, 원본 PNG 복구 |
| CSP · 계정 사용량 | 일부 | 계정 조회와 접속별 요청 제한. 계정 전체 기간별 예산·정확한 사전 비용 계산 남음 |
| 공통 · 백업/공유 | 일부 | 설정 JSON, 생성 기록, 원본 PNG, 삽화 포함 독립 HTML. 전체 참조 파일 백업과 오토픽 이관 남음 |
| 상태 플러그인 · 편집 보호/작업 표시 | 구현 | 대기열과 분석 상태, 입력 초안 분리. 상시 폴링 없음 |

## 확인한 사용자 동작

- ST 구조를 모사한 밝은/어두운 테마 테스트 페이지에서 접이식 설정 패널 확인.
- 장면 분석 → 편집 → 문단 사이 이미지 삽입 → 새 시드 리롤 확인.
- 드래그로 `(0.767, 0.384)`로 옮긴 좌표가 생성 기록까지 그대로 저장됨을 UI에서 확인.
- 방향키 이동 시 숫자 좌표 동기화 확인.
- V4.5 격자/V5 자유 좌표와 실제 요청 중심 좌표의 일치 자동 테스트.
- 검수 모의 응답 표시와 원본 보존 확인.
- 실제 LLM/NovelAI 생성 품질은 별도 검증 필요.

## 0.2.1 실제 ST 화면 검증

- 설치된 ST 1.19.0 staging, 사용자 밝은 테마, JS-Slash-Runner/Memoria/Interpres가 함께 있는 확장 패널에서 재현 및 수정.
- 수정 전 menu_button 폭 28~37px와 한글 세로 줄바꿈 확인. 수정 후 가로 탭 폭 약 59px(데스크톱 2열 패널), 70px(390px 화면)·높이 32px·nowrap 확인.
- 가로 값을 960으로 편집하고 다른 탭을 왕복해도 유지됨을 확인. 실제 사용자 설정을 저장하는 작업은 하지 않음.
- 서버 미연결 상태에서 참조/갤러리 안내, 숨긴 고급 입력, 키보드 탭 이동을 확인.
- 실제 설치본 수정 전 네 파일을 .research/installed-ui-backup-20260921-010430에 백업. config.yaml과 다른 확장의 코드는 수정하지 않음.
