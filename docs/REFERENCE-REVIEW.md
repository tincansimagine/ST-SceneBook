# 씬북 레퍼런스 검토 및 설계 수정

작성일: 2026-09-20. 이 문서는 **구현 완료 목록이 아니라 참고 자료의 분석과 구현 요구사항**이다.

## 검토 범위와 한계

`ref`에는 581개 파일, 약 62.8 MB가 있다. 오토픽 35개(숨김 Git 메타데이터 포함), ComfyUI 계열 541개, Crack Scene Painter 1개, 라이트보드 CHARX 3개, 동반 상태 플러그인 1개다. 실행 파일·이미지·잠금 파일까지 모두 코드처럼 읽었다고 주장하지 않는다.

- 오토픽: 프런트엔드, 설정, 구형 서버, 별도 서버 플러그인.
- Crack Scene Painter 5.1.2: 13,515줄의 함수·설정·UI 전체 구조를 색인화하고 장면 분석, 문맥, 인물, 저장, 재생성, 모델 분기 경로를 검토.
- 라이트보드: 4.1.0-soya-v67, 4.4.0, 4.5.0 CHARX 각각의 `card.json`을 열어 로어북 항목을 분리. 구버전 보조 분석/대사/복구와 최신 버전의 자연어·태그 모드/부분 수정 차이를 비교.
- ComfyUI 서버: 삽화 파이프라인, 의상·외형 타임라인, 대기열, 이력, 원본 에셋, 카메라, 다중 인물, 품질 검수, 프롬프트 파서, 워크플로 기능표, UI 및 관련 테스트를 교차 검토. 영상·LoRA 학습·원격 GPU 설치 등은 별도 기능군으로 분류.
- `lightboard_illust_status.js`: 실제 작업 감지, 폴링 종료, 서버 기능 협상, 편집 중 설정 동기화 보호를 검토.

정적 코드와 테스트 내용에서 확인한 동작이다. 타 프로그램을 설치해 모든 기능을 실사용 검증한 결과와 혼동하지 않는다. 원본 테스트도 아직 실행하지 않았다. 외부 API의 최신 지원 여부는 별도로 공식 자료와 대조한다.

관련 테스트 이름은 기능을 찾는 색인으로 사용했고 중요한 경로는 구현 본문과 대조했다. 테스트 이름만으로 모두 검증됐다고 취급하지 않는다.

### 별도 분류한 주변 기능

이 서버에는 LoRA 학습, Modal/Vast 원격 GPU, Comfy 설치·모델 다운로드, 영상 생성·업스케일, 포즈 검출, 에셋 배치 생성, 캐릭터 제작 도구도 포함된다. 삽화 확장에 필요한 접점(진행상태·원본/설정 보존·취소·공급자 기능 구분)은 채택한다. 서버 전체나 학습/인프라 관리 UI를 ST 확장에 옮기는 것과 '장점을 반영한다'는 것을 혼동하지 않는다. ComfyUI 연결은 NAI 필드를 재활용한 가짜 호환 대신 별도 어댑터가 필요하다.

## 5. 오토픽에서 유지할 ST 특화 장점과 바꿀 부분

- 채팅별 삽화, 인물 프롬프트/프리셋 연결, 수동 생성용 Connection Profile, 이미지별 리롤과 스와이프, 스크롤 복원은 반드시 유지할 사용 경험이다.
- `AutoPic/index.js`의 전역 `window.fetch` 교체는 다른 확장과 충돌할 여지가 있으므로 새 전용 API로 대체.

- 키·프롬프트·이미지 원문을 일반 콘솔 로그에 남기지 않음.
- ST 설치 폴더명에 의존하지 않도록 리소스 경로를 모듈 URL 기준으로 해석.

## 6. 이미 만든 초안에서 수정해야 할 것

## 7. 수용 기준

기능 이름만 추가하거나 UI 버튼만 만드는 것으로 완료 처리하지 않는다.

- 과거 장면 생성에 미래 메시지/현재 복장이 유입되지 않는다.
- 같은 턴의 앞/뒤 장면에서 의상이 바뀌면 각 시점에 맞게 나온다.
- 사용자/캐릭터/채팅/스와이프/분기가 섞이지 않는다.
- 동일 메시지의 중복 이벤트·더블클릭·다중 탭으로 의도치 않은 중복 생성을 막는다.
- 전체 중 1장 실패 시 성공한 그림과 분석은 남는다.
- 재생성 실패/중지/네트워크 단절 후에도 기존 그림이 남는다.
- API 타임아웃을 무료 실패라고 가정해 자동으로 유료 재전송하지 않는다.
- 모델 변경 후 미지원 레퍼런스/좌표/스케줄러 설정이 조용히 섞이지 않는다.
- 프롬프트/인물/소스의 HTML이 UI에서 실행되지 않는다.
- 긴 채팅에서 모든 이미지를 매번 다시 저장하거나 전체 DOM을 재검색하지 않는다.
- 좁은 화면·키보드·포커스 복귀·스크롤 유지까지 확인한다.
- 실계정 API 검증을 하지 못한 기능은 그 사실을 문서와 결과 보고에 명시한다.

## 독립 구현 원칙

오토픽 외 자료의 고유 프롬프트, 코드, 이름, UI 자산을 복제하거나 변수명만 바꿔 배포하지 않는다. 이 문서에는 해결하는 문제와 외부에서 관찰 가능한 기능을 정리하고, 씬북의 자료 구조·프롬프트·UI·테스트는 새로 작성한다. 다른 자료의 라이선스가 있는 경우에도 코드 재사용 여부와 허용 조건을 별도로 판단한다. `ref`와 `.research`는 배포 패키지에서 제외한다.
