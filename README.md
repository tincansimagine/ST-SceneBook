# 씬북 (SceneBook)

SillyTavern 채팅에 NovelAI 삽화를 생성하고 삽입하는 확장입니다.

이 확장은 **깡통 커뮤니티에서 배포된 SillyTavern용 오토픽(AutoPic) 확장**을 참고하여 제작했습니다. 원작자의 허락을 받아 참고했으며, 오토픽 제작자에게 감사드립니다.

버전 **0.4.8** · Node.js 20 이상 · SillyTavern 1.13.3 이상

0.4.8은 채팅 삽화 삭제가 끝난 뒤 확대창을 닫으면서 `Cannot read properties of undefined (reading 'close')` 오류 알림이 뜨던 문제를 수정합니다. 갤러리에서 다시 삽입한 이미지에도 적용됩니다. 확장만 업데이트하고 브라우저를 새로고침하세요. 서버 플러그인 교체·재시작은 필요 없으며 저장된 설정은 변경하지 않습니다. 요청에 따라 실행 테스트·실제 생성 호출 없이 제공합니다.

0.4.7은 **이미지 읽기 → 설정에 적용**에서 빠지던 메인·UC 프롬프트를 생성 옵션과 함께 저장합니다. **생성 → 프롬프트**에서 적용된 내용을 확인할 수 있습니다. 캐릭터 프롬프트·캐릭터 UC·좌표·시드는 가져오지 않으며 기존 인물 라이브러리는 유지합니다. 원문에 포함된 품질 태그가 중복되지 않도록 자동 품질 태그 추가를 끕니다.

이미지 확대창에 확인창이 있는 **삭제**를 추가했습니다. 채팅에서 해당 삽화의 모든 버전을 제거하되 갤러리 원본은 남깁니다. 편집창에서도 SillyTavern 기본 알림·테마를 사용하고 별도 하단 플로팅 알림을 제거했습니다. 버전 전환은 이미지 아래 오른쪽의 작은 문자 화살표·숫자만 표시하며, 더 보기 메뉴는 가로로 펼칩니다. 설정·재생성 버튼의 위치·모양은 유지합니다. **서버 0.4.2 이상이면 확장만 업데이트하고 새로고침하세요.** 이번 변경은 요청에 따라 실행 테스트·실제 생성 호출 없이 제공합니다.

삽화 주입은 기존과 같은 **깊이 0 · System**이며 설정 화면에 위치를 표시합니다. 일반 답변에서는 최신 대화 뒤에 배치되지만 ST 프리셋·이어쓰기·API 후처리에 따라 최종 순서는 달라질 수 있습니다. 지시 누락을 줄이기 위해 조용한 대화·작은 동작도 삽화 후보로 삼고, 최종 답변에 완결된 주석을 남기도록 출력 규칙을 보강했습니다. 지시가 없으면 알림과 기록을 남깁니다. 저장된 설정·커스텀 프롬프트는 유지합니다. 사용자 요청에 따라 이번 버전의 실행 테스트·실제 생성 호출은 하지 않았으며, 개별 누락 원인을 주입 깊이만으로 확정하지 않습니다.

## 설치

### 1. 확장

SillyTavern의 **확장 → 확장 설치**에서 이 저장소의 주소를 입력합니다. 이 폴더의 내용이 저장소 최상단에 있어야 합니다.

수동으로 설치하려면 이 저장소를 `SillyTavern/public/scripts/extensions/third-party/autopic2`에 넣으세요. 폴더 바로 아래에 `manifest.json`과 `index.js`가 있어야 합니다.

### 2. 서버 플러그인

이미지 생성에는 별도 서버 플러그인이 필요합니다. 확장 설치만으로 자동 설치되지는 않습니다.

1. 이 저장소의 `server-plugin/autopic2` 폴더를 `SillyTavern/plugins/autopic2`에 복사합니다.
2. `SillyTavern/plugins/autopic2/index.mjs`와 `package.json`이 있는지 확인합니다.
3. SillyTavern의 `config.yaml`에서 `enableServerPlugins: true`로 설정합니다.
4. SillyTavern 서버를 재시작합니다. 추가 npm 패키지 설치는 필요하지 않습니다.
5. SillyTavern API 연결에서 NovelAI 키를 저장합니다.

서버 파일을 한꺼번에 교체하려면 설치된 이 확장 폴더에서 `node install-server.mjs`를 실행하세요. 압축 해제한 폴더라면 `node install-server.mjs /실제/SillyTavern/경로`로 경로를 지정합니다. 기존 파일은 ST의 backups에 보관하고 사용자 설정·API 키·config.yaml은 변경하지 않습니다.

0.4.8은 확장 업데이트만 필요합니다. 서버 0.4.2 이상이 실행 중이면 다시 교체하지 않아도 됩니다. 처음 설치하거나 구형 서버의 디렉터리 오류가 있는 경우에만 위 서버 설치 절차를 진행하세요. 루트의 `plugin/core.mjs`는 확장에서도 사용하는 공통 모듈이므로 삭제하면 안 됩니다.

### 3. 연결 설정

**확장 설정 → 씬북**에서 연결 상태와 자동 생성 값을 확인하세요. 자동 생성에는 현재 대화 AI가 작성한 삽화 지시를 사용합니다. 별도 분석이 필요할 때만 수동 분석에서 프로필을 선택하세요. 실제 캐릭터 또는 그룹 채팅을 연 뒤 사용하세요.

Vertex는 선택한 프로필의 프리셋·인증 방식·키·리전을 사용합니다. 키는 ST의 사용자별 서버 저장소에서만 읽으며 채팅의 활성 프로필이나 활성 키를 변경하지 않습니다. 키를 새로 입력하기 전에 확장과 서버 플러그인을 모두 업데이트하세요.

## 사용

- **알림**: 분석·생성 중에는 진행 알림을 유지하며 완료·실패를 별도로 표시합니다. 편집 창을 닫아도 실패 알림을 받을 수 있습니다.

- **설정 보존**: 입력값은 자동 저장됩니다. 저장 안 됨 메시지가 있으면 해당 값을 수정하세요. 프리셋·백업 → 이전 설정에서 이 버전 이후 보관한 변경 전 설정을 복구할 수 있습니다.
- **사용법**: 처음 시작하는 순서와 기능별 설명을 찾습니다.
- **자동 생성**: 기본 프롬프트 주입 → AI가 답변과 삽화 지시 작성 → 바로 이미지 생성·삽입. 추가 분석 호출이 없습니다. 생성 전에 검토하려면 처리 방식을 초안만으로 선택하세요.
- **매 답변 생성**: 생성 → 자동 생성 한도에서 **답변 간격을 1로 설정해야 답변마다 그림이 생성됩니다.** 프롬프트 주입을 켜고 처리 방식을 자동 생성으로 선택하세요. 유효한 삽화 지시·연결 상태·요청 한도도 충족해야 합니다.
- **프롬프트 주입**: 켜기·끄기 스위치입니다. 끄면 삽화 지시 주입과 자동 처리를 모두 멈춥니다. 상단 프롬프트 버튼에서 기본 지시문을 확인·수정하고 적용하면 바로 저장됩니다. 지시가 없는 답변은 건너뛰고, 잘못된 지시는 오류를 알립니다.
- 답변 아래의 삽화·직접 작성 버튼은 표시하지 않습니다. 초안은 설정의 장면 편집, 기존 그림은 이미지 위 톱니바퀴로 엽니다.
- **이미지 읽기**: NovelAI 원본 PNG의 메인·UC 프롬프트와 생성 설정을 가져옵니다. 캐릭터 프롬프트·캐릭터 UC·좌표·시드는 제외합니다. 설정에 적용은 공통 설정을 저장하고, 장면으로 열기는 이번 장면으로만 가져옵니다. 파일은 브라우저에서 읽습니다.
- **장면 편집**: 프롬프트·인물 이름·순서·좌표·삽입 문단을 수정합니다. 삽입 위치에서 원문을 읽고 검색해 문단을 고를 수 있습니다. 삭제 확인과 되돌리기를 지원합니다.
- **최종 프롬프트**: 실제로 보낼 문자열을 직접 수정합니다.
- **설정**: 편집 중인 작업의 모델·해상도·시드·샘플링을 변경합니다.
- **생성**: 검토한 장면의 이미지를 요청합니다.
- 이미지 오른쪽 위 **톱니바퀴**로 설정·편집하고, 그 옆 회전 화살표로 바로 재생성합니다. 여러 버전은 **이미지 아래 오른쪽**의 배경 없는 작은 화살표·숫자로 전환합니다. 이미지 자체를 누르면 확대·원본 저장·삭제 창이 열리며 시드·비교·검수는 그 창의 **…**에 있습니다.
- **삽화 삭제**: 확대창의 삭제 → 확인 후 채팅에서 해당 삽화와 이전 버전을 제거합니다. 원본은 갤러리에 남으며 다시 삽입할 수 있습니다. 삭제 후 대기 중인 재생성은 취소하고, 이미 생성 중인 결과는 갤러리에만 보관합니다.
- **프롬프트 → 편집 · 공유**: 공통 이미지 프롬프트와 답변 분석·주입 템플릿을 수정하고 JSON으로 주고받습니다.
- **갤러리**: 작은 썸네일, 제목·프롬프트 검색, 현재 채팅·미완료 필터, 24개씩 페이지 표시. 최근 서버 작업 100개와 현재 채팅의 과거 그림을 조회합니다. 썸네일을 눌러 삽입·편집하고, **…**에서 채팅을 내보냅니다.
- **작업 → … → 지시 기록**: 화면에서 숨긴 삽화 지시와 건너뛴 이유·처리 오류를 확인합니다. 유효한 지시는 장면 편집으로 이어갈 수 있습니다.
- **자동 복구**: 먼저 JSON을 그대로 읽고, 실패하면 로컬 형식 복구 후 장면·좌표·삽입 위치를 확인합니다. 이미 유효한 문자열은 보호하며, 제외된 장면과 복구 내역은 원문과 함께 남깁니다. 닫는 주석 없이 중단된 답변은 자동 생성하지 않습니다.

형식 복구 모듈 [jsonrepair 3.15.0](https://github.com/josdejong/jsonrepair)은 ISC 라이선스로 동봉했습니다. 출처와 라이선스는 `src/vendor/jsonrepair`에 있습니다.

## 지원 범위

- NovelAI V5 Full / Curated, V4.5 Full / Curated
- V5 자유 좌표·투명 배경, V4.5 격자 배치·Vibe / Precise Reference
- 인물 라이브러리·외형 프로필·채팅별 설정·POV·정밀 시점 분석
- 수동 생성·자동 분석 후 검토·자동 생성·대기열·결과 이력
- PNG 일반 텍스트 / 압축 텍스트 / 알파 채널 메타데이터 읽기

V5에는 이미지 참조를 적용할 수 없습니다. PNG 메타데이터 가져오기는 Img2Img / Inpaint 원본과 참조 이미지 인코딩을 복원하지 않습니다. 원본 정보가 제거된 이미지나 스크린샷은 설정을 복구할 수 없습니다.

분석은 선택한 LLM의 사용량을, 이미지 생성은 NovelAI 한도 또는 Anlas를 사용합니다. 비용 보호는 해상도·Steps 제한이며 무료 생성을 보장하지 않습니다. 자동 생성은 기본으로 켜져 있습니다. 업데이트는 저장된 켜기/끄기와 답변 간격을 그대로 유지합니다. 중단된 답변·Quiet 요청·중복 이벤트는 생성하지 않으며, 실패한 요청을 자동 재시도하지 않습니다.

현재 개발 빌드입니다. 로컬 UI·가상 생성·자동 테스트를 확인했으며, 실제 계정의 유료 이미지 생성 품질은 아직 검증하지 않았습니다.

설치 폴더와 내부 저장 키 `autopic2`는 기존 설정·이미지 호환을 위해 유지합니다. 화면 이름은 씬북입니다.
