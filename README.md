# 씬북 (SceneBook)

SillyTavern 채팅에 NovelAI 삽화를 생성하고 삽입하는 확장입니다.

이 확장은 **깡통 커뮤니티에서 배포된 SillyTavern용 오토픽(AutoPic) 확장**을 참고하여 제작했습니다. 원작자의 허락을 받아 참고했으며, 오토픽 제작자에게 감사드립니다.

버전 **0.3.0** · Node.js 20 이상 · SillyTavern 1.13.3 이상

## 설치

### 1. 확장

SillyTavern의 **확장 → 확장 설치**에서 이 저장소의 주소를 입력합니다. 이 폴더의 내용이 저장소 최상단에 있어야 합니다.

수동으로 설치하려면 이 저장소를 `SillyTavern/public/scripts/extensions/third-party/autopic2`에 넣으세요. 폴더 바로 아래에 `manifest.json`과 `index.js`가 있어야 합니다.

### 2. 서버 플러그인

이미지 생성에는 별도 서버 플러그인이 필요합니다. 확장 설치만으로 자동 설치되지는 않습니다.

1. 이 저장소의 `server-plugin/autopic2` 폴더를 `SillyTavern/plugins/autopic2`에 복사합니다.
2. `SillyTavern/plugins/autopic2/index.mjs`와 `package.json`이 있는지 확인합니다.
3. SillyTavern의 `config.yaml`에서 `enableServerPlugins: true`로 설정합니다.
4. SillyTavern 서버를 재시작합니다. 추가 npm 패키지 설치는 필요하지 않습니다.
5. SillyTavern API 연결에서 NovelAI 키를 저장합니다.

업데이트할 때는 확장과 서버 플러그인을 함께 갱신하고 서버를 재시작하세요. 루트의 `plugin/core.mjs`는 확장에서도 사용하는 공통 모듈이므로 삭제하면 안 됩니다.

### 3. 연결 설정

**확장 설정 → 씬북 → 생성**에서 장면 분석에 사용할 연결 프로필을 선택하고 저장하세요. 직접 프롬프트를 작성할 때는 분석 프로필이 없어도 됩니다. 실제 캐릭터 또는 그룹 채팅을 연 뒤 사용하세요.

## 사용

- **사용법**: 처음 시작하는 순서와 기능별 설명을 찾습니다.
- **분석 / 삽화**: LLM이 대화에서 장면과 이미지 프롬프트 초안을 만듭니다.
- **직접 작성**: 분석 없이 프롬프트를 작성합니다.
- **이미지 읽기**: NovelAI 원본 PNG의 메타데이터를 읽고 생성 설정·프롬프트·인물을 가져옵니다. 파일은 브라우저에서 읽습니다.
- **장면 편집**: 프롬프트·인물 이름·순서·좌표·삽입 문단을 수정합니다. 삭제 확인과 되돌리기를 지원합니다.
- **최종 프롬프트**: 실제로 보낼 문자열을 직접 수정합니다.
- **설정**: 편집 중인 작업의 모델·해상도·시드·샘플링을 변경합니다.
- **생성**: 검토한 장면의 이미지를 요청합니다.
- 이미지 위 **톱니바퀴**는 편집, **회전 화살표**는 새 시드 재생성입니다. **같은 시드**와 **시드 사용**도 제공됩니다.
- **프롬프트 → 편집 · 공유**: 공통 이미지 프롬프트와 장면 분석 템플릿을 수정하고 JSON으로 주고받습니다.
- **갤러리**: 생성 기록·이전 결과·다시 삽입·채팅 HTML 내보내기를 사용합니다.

## 지원 범위

- NovelAI V5 Full / Curated, V4.5 Full / Curated
- V5 자유 좌표·투명 배경, V4.5 격자 배치·Vibe / Precise Reference
- 인물 라이브러리·외형 프로필·채팅별 설정·POV·정밀 시점 분석
- 수동 생성·자동 분석 후 검토·자동 생성·대기열·결과 이력
- PNG 일반 텍스트 / 압축 텍스트 / 알파 채널 메타데이터 읽기

V5에는 이미지 참조를 적용할 수 없습니다. PNG 메타데이터 가져오기는 Img2Img / Inpaint 원본과 참조 이미지 인코딩을 복원하지 않습니다. 원본 정보가 제거된 이미지나 스크린샷은 설정을 복구할 수 없습니다.

분석은 선택한 LLM의 사용량을, 이미지 생성은 NovelAI 한도 또는 Anlas를 사용합니다. 비용 보호는 해상도·Steps 제한이며 무료 생성을 보장하지 않습니다. 자동 생성은 기본으로 꺼져 있습니다.

현재 개발 빌드입니다. 로컬 UI·가상 생성·자동 테스트를 확인했으며, 실제 계정의 유료 이미지 생성 품질은 아직 검증하지 않았습니다.

설치 폴더와 내부 저장 키 `autopic2`는 기존 설정·이미지 호환을 위해 유지합니다. 화면 이름은 씬북입니다.
