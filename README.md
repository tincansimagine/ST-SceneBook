# 씬북 (SceneBook)

SillyTavern 채팅에 NovelAI 삽화를 생성하고 삽입하는 확장입니다.

이 확장은 **깡통 커뮤니티에서 배포된 SillyTavern용 오토픽(AutoPic) 확장**을 참고하여 제작했습니다. 원작자의 허락을 받아 참고했으며, 오토픽 제작자에게 감사드립니다.

버전 **0.6.6** · Node.js 20 이상 · SillyTavern 1.13.3 이상

0.6.6은 외부 코드 리뷰(Gemini) 결과를 실제 코드, NovelAI 공식 문서, NovelAI 태그 사전과 대조해서 맞는 것만 고쳤습니다.

- **삽화 지시 읽기**: 대화 AI가 계획을 `xml` · `text` 같은 다른 이름의 코드 블록으로 감싸거나, `[scene 1]` 머리줄, `**prompt:**` 같은 굵은 글씨 키, `- ` · `1.` 목록으로 적어도 읽습니다. 예전에는 계획을 못 찾거나 빈 장면만 만들어 그림이 나오지 않았습니다. 정밀 분석의 상태 추적과 AI 검수도 답에 생각 · 설명 · 코드 블록이 섞여 있어도 결과를 찾습니다. 짝이 맞지 않는 괄호가 많은 답에서 몇 초씩 멈추던 것도 고쳤습니다.
- **설정 하나가 깨졌을 때**: 예전 버전에서 남은 프리셋 · 액자 · 다른 캐릭터의 인물 설정 하나가 지금 규칙에 맞지 않으면, 자동 삽화 · 그림 누르기 · 버전 넘기기가 모두 멈췄습니다. 이제 그림을 그릴 때는 그 항목만 빼고 진행합니다. 저장할 때는 지금처럼 막고 어느 프리셋이 문제인지 이름을 알려 줍니다. 자동 처리 값이 깨졌으면 그리기가 아니라 끄기로 둡니다.
- **채팅 파일 크기**: 답변 본문을 삽화 지시 기록과 그림 자리마다 한 번씩 더 저장하던 것을 없앴습니다. 새로 만드는 그림부터 적용되고, 기존 그림은 그대로 읽습니다.
- **채팅이 길 때 속도**: 그림을 다시 그릴지 판단할 때 답변 본문과 기록 전체를 매번 글자로 바꾸던 것을, 그림 정보만 비교하도록 줄였습니다.
- **알림**: 그림이 바로 그려지기 시작하면 "생성 대기열에 추가했습니다"를 띄우지 않습니다. 앞 그림을 기다릴 때와 일시정지일 때만 알립니다.
- **Vertex**: 분석 답 길이를 65,536보다 크게 정하면 Vertex 연결에서 오류가 나던 것을, 65,536으로 맞춰 보내도록 고쳤습니다.
- **V5 인물 수**: NovelAI 문서대로 V5 인물 한도를 22명으로 맞췄습니다(이전 32명).
- **V5 인물 참조 경고**: NovelAI 문서에 따르면 인물 참조를 여러 장 쓰면 사람마다 따로 그리지 않고 한 사람으로 섞습니다. 참조 탭에서 인물 참조를 두 장 이상 켜면 알려 줍니다.

프롬프트도 다듬었습니다. 바꾼 태그는 NovelAI 태그 사전에서 모델이 아는 태그인지 확인했습니다.

- **색으로 사람 부르지 않기**: 공통 프롬프트와 상대 인물을 가리킬 때 "은발 소녀"처럼 머리 · 눈 · 옷 색으로 부르지 않고, another나 키 · 체격 · 좌우(the taller man, the girl on the left)로 부르게 했습니다. NovelAI는 공통 프롬프트를 그림 전체에 적용하므로 거기 적은 색이 다른 인물에게 번질 수 있습니다. 색은 그 인물의 프롬프트에만 둡니다.
- **구도 태그**: `three-quarter view`는 NovelAI가 모르는 표기여서 `three quarter view`로 바꿨습니다. 이미 저장된 장면도 보낼 때 고쳐서 보냅니다.
- **감정 · 스킨십 태그**: 지시문에 시선(eye contact, looking at another, averting eyes), 표정(light blush, tears, light smile), 손길(holding hands, interlocked fingers, hand on another's cheek, hug from behind, forehead-to-forehead, imminent kiss), 체격 차이(height difference, size difference, tall male, petite) 태그를 넣어, 분위기 단어 대신 그림에 보이는 태그를 쓰게 했습니다. 같은 설정 기준으로 답변에 붙는 지시는 약 7%(간결한 지시문은 약 13%) 길어졌습니다.
- **인물 순서**: NovelAI는 인물 프롬프트를 위에서 아래, 왼쪽에서 오른쪽 순서로 놓고, 이 순서와 위치가 맞을 때 가장 잘 따릅니다. AI가 쓴 장면은 위치에 맞춰 인물 순서를 정리합니다. 장면 편집에서 직접 바꾼 순서는 그대로 둡니다.
- **그림체와 UC 충돌**: NovelAI 기본 UC의 film grain · screentone이 시네마틱 · 레트로 애니 · 흑백 만화 그림체가 붙이는 태그와 서로 반대로 당겼습니다. 이제 그릴 때 UC 쪽에서 뺍니다. 시네마틱 그림체에서는 NovelAI가 모르는 `wide aspect composition`을 뺐고, 흑백 만화의 `screentone`은 NovelAI 표기인 `screentones`로 바꿨습니다. 이전 그림을 다시 그려도 태그가 겹치지 않습니다.
- **말풍선**: 만화 페이지의 대사는 NovelAI 문서대로 그 인물 프롬프트 맨 끝에 `Text:`로 넣게 했습니다.
- **인물 탭 예시**: 외형 예시를 NovelAI가 아는 태그로 바꿨습니다. 남자 인물 예시(boy, mature male, tall male, broad shoulders)와, 남자가 여성스럽게 나올 때 인물 제외 요소에 넣을 태그(makeup, lipstick)도 적었습니다.

서버 플러그인은 0.5.2입니다. 그림이 많으면 갤러리를 열 때마다 모든 기록 파일을 다시 읽던 것을, 끝난 기록은 한 번만 읽고 한 번에 여는 파일 수도 제한하도록 바꿨습니다. 위의 다른 변경은 확장만 업데이트해도 모두 적용되고, 서버 교체는 갤러리 속도에만 영향이 있습니다. 실제 NovelAI · 대화 AI 호출 없이 SillyTavern을 흉내 낸 환경과 모의 응답으로 검증했으므로, 바뀐 프롬프트의 실제 그림 품질은 직접 확인이 필요합니다.

- **구도 정하는 순서**: AI가 누가 보여야 하는지 → 각자의 자리와 자세 → 그 자리에서 실제 카메라가 설 수 있고 얼굴이나 닿는 곳을 가리지 않는 시점 → 화면 크기 순으로 정합니다. 나란히 누운 둘(위에서), 혼자 누운 사람(위에서, 또는 침대 높이 옆에서), 마주 앉은 둘(옆이나 비스듬히), 욕조(위에서, 또는 수면 높이 옆에서) 같은 예를 넣었습니다. 짧은 지시문에도 같은 순서를 넣었습니다.
- **불가능한 시점 교정**: 누운 사람을 아래에서 보거나 나란히 누운 둘을 옆에서 보는 구도는 위에서 보기로 바꿔 그립니다. 그림 고치기 · 장면 편집에서 직접 적으면 구도 칸 아래에 한 줄 경고와 위에서 보기로 단추가 나옵니다.
- **지시문 정리**: 답변에 붙는 지시에서 "삽화 계획을 꼭 써라"를 여러 번 되풀이하던 부분을 맨 앞 한 번과 맨 끝 점검 한 줄로 합쳤습니다. 구도 규칙을 더했는데도 약 28% 짧아졌습니다(V5, 영어 단어 기준 어림 약 2,950 → 2,130). 짧은 지시문은 구도 규칙만큼 약 3% 늘었습니다. 성인 장면 규칙은 그대로입니다.
- **프롬프트 순서**: 보통 삽화는 인원수 태그를 맨 앞에 두고 메인 프롬프트 → 구도 → 장면 → 품질 태그 순으로 보냅니다. 메인 프롬프트 · 구도와 겹치는 태그와 구도와 어긋나는 시점 태그는 뺍니다. 가중치 묶음은 그대로 둡니다. 서버 플러그인을 바꾸지 않고 씬북이 순서를 정해 보내며, 고치기 화면에는 원래 장면이 그대로 보입니다.

0.4.9는 **참조 탭의 이미지 오른쪽 위에 삭제 버튼**을 추가합니다. 확인 후 업로드한 원본과 등록 정보를 서버에서 삭제하고 적용 목록·프리셋에서도 해제합니다. 해당 참조를 사용하는 대기 작업은 취소하며 이미 생성한 삽화는 유지합니다. 이미지 생성 중에는 완료 후 삭제하도록 안내합니다. 삭제한 참조가 남은 과거 장면은 편집 시 안내하고 제외합니다.

**참조 삭제에는 서버 0.4.4 이상이 필요합니다.** 이전 서버를 사용 중이라면 서버 플러그인도 업데이트한 뒤 SillyTavern 서버를 재시작하세요.

0.4.8에서 수정한 채팅 삽화 삭제 후 `Cannot read properties of undefined (reading 'close')` 오류 개선도 포함합니다. 갤러리에서 다시 삽입한 이미지에도 적용됩니다.

0.4.7은 **이미지 읽기 → 설정에 적용**에서 빠지던 메인·UC 프롬프트를 생성 옵션과 함께 저장합니다. **생성 → 프롬프트**에서 적용된 내용을 확인할 수 있습니다. 캐릭터 프롬프트·캐릭터 UC·좌표·시드는 가져오지 않으며 기존 인물 라이브러리는 유지합니다. 원문에 포함된 품질 태그가 중복되지 않도록 자동 품질 태그 추가를 끕니다.

이미지 확대창에는 확인창이 있는 **삭제**가 있습니다. 채팅에서 해당 삽화의 모든 버전을 제거하되 갤러리 원본은 남깁니다. 편집창에서도 SillyTavern 기본 알림·테마를 사용합니다. 버전 전환은 이미지 아래 오른쪽의 작은 문자 화살표·숫자만 표시하며, 더 보기 메뉴는 가로로 펼칩니다. 설정·재생성 버튼의 위치·모양은 유지합니다.

삽화 주입은 **채팅 완성 요청 조립 후 프리셋 뒤 · 답변 시작문 앞**으로 옮깁니다. 텍스트 완성은 기존 깊이 0을 유지하며 API 후처리가 역할을 변환할 수 있습니다. 지시 누락을 줄이기 위해 조용한 대화·작은 동작도 삽화 후보로 삼고, 최종 답변에 완결된 주석을 남기도록 출력 규칙을 보강했습니다. 지시가 없으면 알림과 기록을 남깁니다. 저장된 설정·커스텀 프롬프트는 유지합니다. 사용자 요청에 따라 이번 버전의 실행 테스트·실제 생성 호출은 하지 않았으며, 개별 누락 원인을 주입 깊이만으로 확정하지 않습니다.

## 설치

### 1. 확장

SillyTavern의 **확장 → 확장 설치**에서 이 저장소의 주소를 입력합니다. 이 폴더의 내용이 저장소 최상단에 있어야 합니다.

수동으로 설치하려면 이 저장소를 `SillyTavern/public/scripts/extensions/third-party/autopic2`에 넣으세요. 폴더 바로 아래에 `manifest.json`과 `index.js`가 있어야 합니다.

### 2. 서버 플러그인

이미지 생성에는 별도 서버 플러그인이 필요합니다. 확장 설치만으로 자동 설치되지는 않습니다.

1. 이 저장소의 `server-plugin/autopic2` 폴더를 `SillyTavern/plugins/autopic2`에 복사합니다.
2. `SillyTavern/plugins/autopic2/index.mjs`와 `package.json`이 있는지 확인합니다.
3. SillyTavern의 `config.yaml`에서 `enableServerPlugins: true`로 설정합니다.
4. SillyTavern 서버를 재시작합니다. 추가 npm 패키지 설치는 필요하지 않습니다.
5. SillyTavern API 연결에서 NovelAI 키를 저장합니다.

서버 파일을 한꺼번에 교체하려면 설치된 이 확장 폴더에서 `node install-server.mjs`를 실행하세요. 압축 해제한 폴더라면 `node install-server.mjs /실제/SillyTavern/경로`로 경로를 지정합니다. 기존 파일은 ST의 backups에 보관하고 사용자 설정·API 키·config.yaml은 변경하지 않습니다.

V5 참조에는 서버 플러그인 0.5.0 이상, V4.5의 새 품질 태그에는 0.5.1, 참조 삭제에는 0.4.4 이상이 필요합니다. 0.5.2는 그림이 많을 때 갤러리를 빨리 엽니다(선택). 위 절차로 서버 플러그인을 교체한 뒤 서버를 재시작하세요. 브라우저 새로고침만으로 서버 코드가 바뀌지는 않습니다. 루트의 `plugin/core.mjs`는 확장에서도 사용하는 공통 모듈이므로 삭제하면 안 됩니다.

### 3. 연결 설정

**확장 설정 → 씬북** 칸을 펼치고 **시작** 탭에서 준비 상태를 확인하세요. 채팅 입력창 왼쪽의 **마법봉 메뉴 → 씬북**으로 같은 내용을 넓은 창으로 열 수도 있습니다. 자동 생성에는 현재 대화 AI가 작성한 삽화 지시를 사용합니다. 별도 분석이 필요할 때만 수동 분석에서 프로필을 선택하세요. 실제 캐릭터 또는 그룹 채팅을 연 뒤 사용하세요.

Vertex는 선택한 프로필의 프리셋·인증 방식·키·리전을 사용합니다. 키는 ST의 사용자별 서버 저장소에서만 읽으며 채팅의 활성 프로필이나 활성 키를 변경하지 않습니다. 키를 새로 입력하기 전에 확장과 서버 플러그인을 모두 업데이트하세요.

## 사용

- **여는 곳**: 확장 설정의 씬북 칸에 모든 탭이 바로 있습니다. 넓은 창은 탭 옆의 확대 버튼, 마법봉 메뉴 → 씬북, 또는 `/scenebook`으로 엽니다. 설정은 바꾸는 즉시 저장됩니다.
- **시작**: 준비 상태, 자동 삽화 켜기/끄기(바로 그리기 · 초안만 저장), 장면 쓰는 곳(답변에 함께 · 답변 후 보조 모델), 최대 응답 길이 안내, 답변 간격, 수동 생성, 장면 편집, 이미지에서 설정 읽기.
- **수동 생성**: 마지막 답변(또는 답변 메뉴의 마법봉 아이콘으로 고른 답변)의 그림을 지금 만듭니다. 저장된 장면 · AI가 장면 쓰기 · 직접 쓰기 중에서 고르고 화면 비율을 정한 뒤 생성을 누릅니다. `/scenegen` 명령은 글이 있으면 직접 쓰기, 없으면 저장된 장면 또는 AI가 장면 쓰기로 동작합니다.
- **자동 삽화**: 켜면 대화 AI가 답변과 함께 삽화 지시를 쓰고 씬북이 바로 그림을 만들어 답변 아래에 넣습니다. 추가 분석 호출이 없습니다. **답변 간격을 1로 두어야 답변마다 그림이 생성됩니다.** 초안만 저장은 장면만 저장하고 생성은 직접 합니다. 끄면 삽화 지시 주입과 자동 처리를 모두 멈춥니다.
- **프롬프트**: 그림체(선택), 메인 프롬프트, 제외할 요소(UC)와 NovelAI 기본 UC 넣기, 품질 태그 자동 추가. 전송 순서는 그림체 → 메인 프롬프트 → 구도 → 장면 → 품질 태그입니다. AI 지시문 · 프롬프트 공유에서 삽화 지시문·수동 분석 지시문을 고치고 JSON으로 주고받습니다.
- **그림 설정**: 모델, 크기(세로 · 가로 · 정사각 · 직접 입력), 장면에 맞춰 세로·가로 바꾸기, Steps · Guidance, 비용 보호, 고급 설정, 수동 분석, 프리셋 · 백업(이전 설정 복구 · 내보내기 · 가져오기).
- **인물**: 이름·고정 외형·기본 복장·외형 프로필을 등록합니다. 저장 범위는 계정 전체 · 현재 캐릭터 · 현재 채팅이며 적용 우선순위는 **채팅 → 캐릭터 → 전체**입니다(목록을 합치지 않음). 다른 범위로 복사와 범위 해제를 지원합니다. 이름이 같은 별도 캐릭터 카드끼리는 설정을 공유하지 않으며, 그룹 채팅에서는 계정 전체·현재 채팅 범위를 사용합니다.
- **참조**: 이미지를 올리고 사용을 켠 뒤 용도(인물 + 그림체 · 인물 · 그림체 · 의상 · 분위기)와 강도를 정합니다. 지금 모델에서 쓸 수 없는 참조는 이유를 표시하고 건너뛰며, 모델을 바꿔도 목록은 유지됩니다. 휴지통은 업로드한 원본과 등록 정보를 삭제하고 적용 목록·프리셋에서도 해제합니다(이미 생성한 삽화는 유지).
- **표시**: 그림 위치(답변 아래 · 문단 뒤), 최대 너비, 작게 표시, 삽화 액자와 장식 색, 액자 그림 추가.
- **갤러리 · 작업**: 갤러리는 최근 서버 작업 100개와 현재 채팅의 그림을 검색·삽입·편집합니다. 작업은 대기열 일시정지·취소, 초안 일괄 생성, 지시 기록, 계정 사용량을 다룹니다.
- **그림 위의 버튼**: 연필은 **그림 고치기**(장면 · 메인 프롬프트 · 그림체 · UC · 구도 · 화면 비율 · 시드 · 인물을 한 화면에서 수정 → 다시 그리기), 회전 화살표는 같은 프롬프트로 다시 그리기입니다. 새 그림은 같은 자리에 버전으로 추가되고 그림 아래 오른쪽의 화살표·숫자로 전환합니다. 그림을 누르면 확대 · 저장 창이 열리며 삭제 · 시드 · 버전 비교 · AI 검수는 그 창의 더 보기에 있습니다.
- **그림 고치기의 메인 프롬프트**: 그 그림을 만들 때 쓴 값이 보이며 고치면 그 그림에만 적용됩니다. 앞으로 그릴 그림에도 적용을 켜면 기본 설정에도 저장합니다. 맨 위 칸에 바꾸고 싶은 점을 말로 적고 AI로 고쳐 쓰기를 누르면 AI가 장면·구도·인물을 고쳐 씁니다.
- **장면 편집**: 각 답변의 메시지 메뉴(…)에 있는 풍경 아이콘, 시작 탭의 장면 편집, 수동 생성 창의 장면 편집, 그림 고치기의 인물 배치 · 설정으로 엽니다. 장면 · 프롬프트 / 인물 · 배치 / 최종 확인 탭이 있으며, 최종 확인에서 직접 고치면 그 장면은 입력한 내용만 그대로 전송합니다.
- **이미지에서 설정 읽기**: NovelAI 원본 PNG의 메인·UC 프롬프트와 생성 설정을 가져옵니다. 캐릭터 프롬프트·캐릭터 UC·좌표·시드는 제외합니다. 설정에 적용은 공통 설정을 저장하고, 장면으로 열기는 이번 장면으로만 가져옵니다. 파일은 브라우저에서 읽습니다.
- **삽화 삭제**: 확대창의 더 보기 → 삭제 → 확인 후 채팅에서 해당 삽화와 이전 버전을 제거합니다. 원본은 갤러리에 남으며 다시 삽입할 수 있습니다.
- **알림**: 분석·생성 중에는 진행 알림을 유지하며 완료·실패를 별도로 표시합니다. 실패한 유료 요청을 자동 재시도하지 않습니다.
- **자동 복구**: 삽화 지시를 그대로 읽지 못하면 형식을 복구한 뒤 장면·좌표를 확인합니다. 닫는 주석 없이 중단된 답변은 자동 생성하지 않습니다. 작업 → 더 보기 → 지시 기록에서 지시와 건너뛴 이유를 확인합니다.

형식 복구 모듈 [jsonrepair 3.15.0](https://github.com/josdejong/jsonrepair)은 ISC 라이선스로 동봉했습니다. 출처와 라이선스는 `src/vendor/jsonrepair`에 있습니다.

## 지원 범위

- NovelAI V5 Full / Curated, V4.5 Full / Curated
- V5 자유 좌표·투명 배경·Precise Reference(인물 · 그림체 · 의상, 여러 장, 강도 0~5)
- V4.5 격자 배치·Vibe·Precise Reference 1장(강도 0~1, 충실도)
- 인물 라이브러리·외형 프로필·계정/캐릭터/채팅별 설정·POV·정밀 시점 분석
- 수동 생성·자동 분석 후 검토·자동 생성·대기열·결과 이력
- PNG 일반 텍스트 / 압축 텍스트 / 알파 채널 메타데이터 읽기

V5에는 분위기(Vibe)를 적용할 수 없고, 참조를 쓴 인페인팅은 지원하지 않습니다. PNG 메타데이터 가져오기는 Img2Img / Inpaint 원본과 참조 이미지 인코딩을 복원하지 않습니다. 원본 정보가 제거된 이미지나 스크린샷은 설정을 복구할 수 없습니다.

분석은 선택한 LLM의 사용량을, 이미지 생성은 NovelAI 한도 또는 Anlas를 사용합니다. 비용 보호는 해상도·Steps 제한이며 무료 생성을 보장하지 않습니다. 자동 생성은 기본으로 켜져 있습니다. 업데이트는 저장된 켜기/끄기와 답변 간격을 그대로 유지합니다. 중단된 답변·Quiet 요청·중복 이벤트는 생성하지 않으며, 실패한 요청을 자동 재시도하지 않습니다.

현재 개발 빌드입니다. 실제 계정의 유료 이미지 생성 품질은 검증하지 않았습니다.

설치 폴더와 내부 저장 키 `autopic2`는 기존 설정·이미지 호환을 위해 유지합니다. 화면 이름은 씬북입니다.
